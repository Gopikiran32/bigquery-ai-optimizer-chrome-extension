◆ BigQuery AI Query Optimizer

Point the extension at the Cloud Function you deployed in your own GCP project.

The HTTPS trigger URL printed at the end of deploy.sh. It usually looks like https://REGION-PROJECT.cloudfunctions.net/bq-query-optimizer or https://bq-query-optimizer-xxxx.REGION.run.app.

Logs query-extraction details to the page console. Leave off unless you are debugging.

Don't have a backend yet?

The extension needs a Cloud Function running in your own project — that is what keeps your SQL and table metadata inside your organisation.

  1. Clone the repository and open the cloud-function/ folder.
  2. Set PROJECT_ID and REGION, then run ./deploy.sh.
  3. Copy the URL it prints into the field above and hit Save.

Full instructions are in the project README.

Privacy

Your SQL is sent only to the URL you configure above. This extension has no analytics, no telemetry, and no third-party endpoints. The URL and the logging toggle are the only things stored, in Chrome's synced extension storage.
